# Survive Tung Island builds

Official distribution repository for Survive Tung Island.

This repository is for the launcher so it can read the games that needs to be downloaded.

Note: *YOU DO NOT HAVE TO DOWNLOAD DIRECTLY FROM THIS REPOSITORY, USE THE LAUNCHER INSTEAD*

### Launcher

The Launcher automatically checks the version manifest for available Vanilla versions and can download installed versions when required, can be installed at itch.

Official launcher link:
https://zakbazooka.itch.io/survive-tung-island
