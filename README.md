# Survive Tung Island Distribution

Official distribution repository for Survive Tung Island.

This repository contains:

- Official Vanilla game versions
- Version manifests
- Release downloads
- Version metadata

The Launcher uses the version manifest to detect available game versions and download official releases.

## Downloads

Official game versions are provided through GitHub Releases.

## Launcher

The Launcher automatically checks the version manifest for available Vanilla versions and can download installed versions when required.
